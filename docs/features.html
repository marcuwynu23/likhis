Features

Core capabilities, supported frameworks, and export formats.

Core Capabilities

What Likhis does out of the box.

Intelligent Route Detection

Uses pattern matching and regex to identify route definitions across different framework conventions with high accuracy.

Breadth-First Traversal

Efficiently scans project directories using a BFS algorithm, prioritizing top-level routes and skipping dependency folders.

Parameter Extraction

Automatically detects path parameters (:id, {id}, <id>), query parameters, and request body fields.

Router Mount Detection

Understands nested router structures and correctly prefixes base paths for frameworks like Express.js.

Environment-Specific Exports

Generate separate collections for dev, staging, and production environments with a single --full flag.

Fast & Lightweight

Written in Go with no external runtime dependencies. Single statically-linked binary runs anywhere.

Supported Frameworks

Likhis works with all major backend frameworks out of the box. Just point it at your project and it will automatically detect which framework you're using.

Express.js Flask Django Spring Boot Laravel FastAPI NestJS Koa Tornado

Likhis reads your route definitions just like you write them — app.get() in Express, @app.route() in Flask, path() in Django, @GetMapping in Spring Boot, Route::get() in Laravel, and more. No matter the framework, the output is the same: a complete, organized API collection ready to import.

Export to Your Favorite Tool

Likhis generates ready-to-import collections for all major API testing tools. Pick the one you use and get started in seconds.

Postman Collection v2.1 JSON with environment variables, path/query params, and request body templates. Import directly into Postman Desktop or web.
Insomnia Native export with workspace structure, request groups, and environment variables. Ready for Insomnia Desktop.
HTTPie Desktop Collection file with metadata, path params, query params, and body support for HTTPie Desktop.
cURL Executable shell script with ready-to-run curl commands. Just bash api-requests.sh.
