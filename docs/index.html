Map your API routes in seconds

A cross-platform CLI tool that automatically scans your backend source code, detects API routes, and generates ready-to-import collections for Postman, Insomnia, HTTPie, and cURL.

Get Started View Usage

Why Likhis?

Automated route discovery that works with your favorite frameworks and tools.

Zero Configuration

Point Likhis at any backend project and it automatically detects the framework and extracts routes with no setup required.

Multi-Framework

Supports Express.js, Flask, Django, Spring Boot, Laravel, and more via an extensible YAML plugin system.

Multiple Export Formats

Generate collections for Postman, Insomnia, HTTPie Desktop, or shell scripts with cURL commands.

YAML Plugin System

Add support for new frameworks by dropping a YAML file into the plugins directory — no code changes needed.

Environment-Aware

Generate separate collections for dev, staging, and production environments with a single command.

Cross-Platform

Written in Go — runs on Windows, macOS, and Linux with a single statically-linked binary.
