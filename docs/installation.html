Installation

Get Likhis up and running on your platform in minutes.

Prerequisites

  • Go 1.21+ (only required for building from source)
  • Windows, macOS, or Linux — fully cross-platform
  • Access to your backend project source code

Option 1: Download Pre-Built Binary

The fastest way to get started. Download the latest release for your platform from the GitHub Releases page.

Linux / macOS
# Download the latest release
curl -LO https://github.com/marcuwynu23/likhis/releases/latest/download/likhis-linux-amd64.tar.gz
tar -xzf likhis-linux-amd64.tar.gz
sudo mv likhis /usr/local/bin/
Windows (PowerShell)
# Download the latest release
Invoke-WebRequest -Uri "https://github.com/marcuwynu23/likhis/releases/latest/download/likhis-windows-amd64.zip" -OutFile likhis.zip
Expand-Archive -Path likhis.zip -DestinationPath likhis
# Add to PATH or move to a directory in your PATH
move .\likhis\likhis.exe C:\Bin\

After downloading, verify the installation:

Terminal
likhis --help

Option 2: Build from Source

If you have Go 1.21+ installed, you can clone the repository and build the binary yourself.

Clone the repository

Terminal
git clone https://github.com/marcuwynu23/likhis.git
cd likhis

Build the executable

Terminal
go build -o build/likhis main.go

Or build using Make:

Terminal
make build

The compiled executable will be located in the build/ directory.

Verify Installation

Run the help command to confirm everything is working:

Terminal
likhis --help

Universal API Mapper Tool

Usage: likhis [options]

Options:
  -F string        Framework to target (default 'auto')
  -O string        Output directory path
  -f string        Output file name
  -full           Generate exports for dev, staging, and production
  -o string        Output format: postman, insomnia, httpie, curl (default 'postman')
  -p string        Path to project root directory (default '.')

Quick Start

Once installed, try Likhis on any backend project:

Terminal
# Scan current directory and generate Postman collection
likhis -p . -o postman

# Scan a specific project with auto-detection
likhis -p ./my-backend -o insomnia

# Generate for a specific framework
likhis -p ./express-app -o postman -F express

# Generate environment-specific exports
likhis -p ./my-api -o postman --full
