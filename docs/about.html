About Likhis

Understanding the tool, its pipeline, and the concepts behind it.

Overview

Likhis is a high-performance, cross-platform command-line tool written in Go that automatically analyzes backend source code to discover API routes, extract HTTP methods and parameters, and generate ready-to-import collections for popular API testing tools.

It eliminates manual route documentation by intelligently parsing your codebase and producing standardized exports compatible with Postman, Insomnia, HTTPie Desktop, and cURL. Whether you're onboarding new team members, generating documentation, or setting up API tests, Likhis saves hours of tedious work.

Key Benefits

  • Zero Configuration — Point Likhis at any backend project and it just works. No setup, no config files.
  • Multi-Framework Support — Works with Express.js, Flask, Django, Spring Boot, Laravel, and more.
  • Export to Any Tool — Generate collections for Postman, Insomnia, HTTPie Desktop, or cURL scripts.
  • Environment-Aware — Generate separate collections for dev, staging, and production with a single flag.
  • One Binary, Anywhere — A single statically-linked binary runs on Windows, macOS, and Linux.

When to Use Likhis

Onboarding new team members

Hand your new developer a Postman collection generated by Likhis instead of asking them to read through router files. They can start hitting your API endpoints immediately.

API documentation generation

Keep your API collections in sync with your codebase. Run Likhis after every significant change and your Postman or Insomnia exports are always up to date — no more stale docs.

Setting up test environments

Need separate collections for dev, staging, and production? Likhis generates all three in a single command. Each environment gets its own base URL and configuration.

Legacy codebase discovery

Inherited a large project with undocumented routes? Likhis scans everything and produces a complete map of all API endpoints with their methods and parameters.
